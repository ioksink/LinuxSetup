# Fedora R Recovery Log
1. The Situation

Following a system crash during an update, the Fedora installation was left in a "corrupted" state. The RPM database was out of sync, and the R environment was missing critical links to system libraries, preventing the installation of the Tidyverse and Phyloseq.

2. Phase I: Repairing the Foundation

The Issue: dnf was broken, reporting 404 errors and transaction failures.
The Fix:
- Cleaned and rebuilt the package database: sudo dnf clean all and sudo dnf makecache.
- Repaired the broken RPM transaction.
- Installed the core Development Group: sudo dnf group install "Development Tools".

3. Phase II: The "Alphabet" (Compilers & Headers)

The Issue: R could not compile packages because C++ headers (cstdio, cstring) were missing.

The Fix: Installed the C++ compiler and standard library development files:
```Bash
sudo dnf install @development-tools @c-development
sudo dnf install gcc-c++ libstdc++-devel gcc-gfortran
```
Ensured the Fortran package exists and R could find the Fortran compiler by creating a symlink:

```Bash
gfortran --version
sudo ln -s /usr/bin/gfortran-16 /usr/bin/gfortran
```

## 4. Phase III: The Graphics Stack
**The Issue:** Installing `systemfonts` (for Tidyverse) failed because of missing `ft2build.h` and `bzip2.pc`.

**The Fix:** Installed the font and compression headers:
	
```bash
sudo dnf install freetype-devel fontconfig-devel bzip2-devel libpng-devel
```
Manual Fix: Fedora's `bzip2-devel` was missing the `.pc` metadata file, so we manually created `/usr/lib64/pkgconfig/bzip2.pc` to satisfy `pkg-config`. 

> Do this in commandline: `pkg-config --list-all | grep <filename>.pc`

## 5. Phase IV: The Math Engine (The Final Boss)
The Issue: Compiling `vegan` and `phyloseq` failed because the Linker couldn't find `-lflexiblas` and `-lquadmath`.

The Fix: Installed the development versions of the math libraries:
	
```bash
sudo dnf install flexiblas-devel libquadmath-devel lapack-devel
```
The Symlink Repair: 

```bash
ls -l /usr/lib64 | grep "libquadmath" 
ls -l /usr/lib64 | grep "libflexiblas" 
```
Directly look for libraries in the folder. The system had the libraries for *running* programs but was missing the "Development Links" for *building* them. We manually bridged them:

```bash
sudo ln -s /usr/lib64/libflexiblas.so.3 /usr/lib64/libflexiblas.so
sudo ln -s /usr/lib64/libquadmath.so.0 /usr/lib64/libquadmath.so
```

## Final Status
*   **R Version:** 4.6 (Fedora Rawhide/44)
*   **Math Backend:** OpenBLAS via FlexiBLAS (High Performance)
*   **Compiler Stack:** GCC 16 (C, C++, Fortran)
*   **Major Packages Installed:** `tidyverse`, `systemfonts`, `vegan`, `phyloseq`.

### Lessons Learned
1.  **Libraries ≠ Headers:** On Fedora, always install the `-devel` version of a library if you plan to use it in R.
2.  **.so.X vs .so:** Running a program uses the numbered file; compiling a program uses the unnumbered symlink.
3.  **Persistence Pays Off:** System crashes during updates can be fixed without a reformat by systematically addressing missing file errors one by one.

# Quarto

There is no rpm package for quarto, so we have to install [tarball](https://quarto.org/docs/download/). Decompress the file and link the file to user bin. `sudo ln -s /home/melissa/gitClone/quarto-1.9.37-linux-amd64/quarto-1.9.37/bin/quarto /usr/local/bin/quarto` And then check with `quarto --version`.

To use it with R, you still need to install quarto in R. Type `install.packages("quarto")` in R terminal.

## SVG image convert

Another function used in rendering qmd files with svg images is rsvg-convert, which is found in system via `sudo dnf install librsvg2-tools`.

## System latex conflict with quarto

> ERROR: Problem running `fmtutil-sys --all` to rebuild format tree.

Running this command with sudo is completely alright, however, quarto does not have sudo privilege. You can decide whether to remove system latex and use the tinytex package

```zsh
sudo dnf remove "texlive-*"
quarto install tinytex
```
or keep the system latex package (installed with dnf) and install .sty files.

```zsh
sudo dnf install 'tex(setspace.sty)'
```
